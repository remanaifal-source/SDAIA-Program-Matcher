## Project Overview

**Program Matcher** is an AI-powered feature designed to enhance the **SDAIA Academy** website by helping users identify the most suitable training program based on their education, programming experience, interests, and career goals.
Instead of manually browsing through all available programs, users complete a short questionnaire and receive personalized recommendations, including the recommended program, compatibility score, explanation, and required skills.


### Install dependencies

```bash

```

### Run the development server

```bash

```

# How to Use the Application

1. Open the application.
2. Create an account or sign in.
3. Click **Start Matching**.
4. Answer the questionnaire about your background, interests, and career goals.
5. Receive an AI-powered recommendation that includes:
   - Best matching SDAIA Academy program
   - Compatibility percentage
   - Recommendation explanation
   - Required skills
6. Explore recommended programs and learn more about each one.
